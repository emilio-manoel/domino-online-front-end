# 🎲 Domino Online - Front-End

## 📌 Sobre o Projeto

O **Domino Online - Front-End** é a interface da aplicação **Domino Online**, um projeto Full-Stack que representa a evolução do **Domino Game**, desenvolvido anteriormente como um mini desafio acadêmico durante a graduação em Análise e Desenvolvimento de Sistemas.

Enquanto o primeiro projeto tinha como foco apenas a implementação das regras do jogo em JavaScript, esta versão foi completamente reformulada para oferecer uma experiência multiplayer em tempo real, utilizando uma arquitetura moderna baseada na separação entre front-end e back-end.

O objetivo deste projeto é proporcionar uma interface intuitiva e dinâmica para que os jogadores possam criar salas, participar de partidas e acompanhar todas as ações do jogo sincronizadas em tempo real.

---

# 🚀 Tecnologias Utilizadas

## ⚛️ React

O projeto foi desenvolvido utilizando **React**, permitindo construir a interface através de componentes reutilizáveis.

Essa abordagem facilita a organização do código, melhora a manutenção da aplicação e torna o desenvolvimento mais escalável conforme novas funcionalidades são adicionadas.

---

## ⚡ Vite

O **Vite** foi utilizado como ferramenta de desenvolvimento e build da aplicação.

Ele oferece inicialização extremamente rápida, atualização instantânea durante o desenvolvimento (Hot Module Replacement) e uma configuração moderna para projetos React.

---

## 🔷 TypeScript

Toda a aplicação foi escrita em **TypeScript**, adicionando tipagem estática ao JavaScript.

Isso proporciona maior segurança durante o desenvolvimento, facilita a identificação de erros antes da execução e torna o código mais organizado e legível.

---

## 🌐 Socket.IO Client

A comunicação em tempo real foi implementada utilizando **Socket.IO Client**.

Essa biblioteca permite que o front-end estabeleça uma conexão persistente com o servidor através de WebSockets, recebendo atualizações instantaneamente sem a necessidade de recarregar a página.

Graças ao Socket.IO Client, ações como entrada de jogadores, movimentação das peças, atualização do tabuleiro e demais eventos da partida são sincronizados automaticamente entre todos os participantes.

---

## 🎨 CSS

O CSS foi utilizado para construir toda a identidade visual da aplicação, organizando os componentes e proporcionando uma experiência agradável durante as partidas.

Este projeto representou um grande avanço na minha formação como futuro **Desenvolvedor Full-Stack**.

Durante seu desenvolvimento foi possível aprofundar conhecimentos em:

* desenvolvimento de interfaces modernas com React;
* componentização de aplicações;
* utilização prática do TypeScript;
* gerenciamento de estado da interface;
* comunicação em tempo real utilizando Socket.IO Client;
* consumo de serviços disponibilizados pelo back-end;
